# AILab 微信小程序家长端

微信原生 JavaScript / WXML / WXSS，四个一级入口：**首页｜守护｜成长｜我的**。

当前是可操作、可保存本地状态的功能模拟版本。定位、通话、设备指令、账号关系与探索记录均未接真实服务；界面用“演示数据”作简洁说明。不上传、不发布、不推送远程仓库。

## 本轮重点改进

- **首页**：陪伴概览、待办、按日期排列的动态、类型筛选、兴趣足迹及只读成果；累计数据不再被称作“今日”数据。
- **守护**：真实 map 组件呈现模拟当前点位；定位过期、离线及解绑清坐标。语音、查找、联系人、闹钟与紧急联系人具备过程、结果和恢复入口。
- **成长**：从同一批探索事件生成进度、六维、维度依据和成果。解锁不算完成，重复完成不重复计数；数据未知与已知 0% 区分展示。
- **报告**：生成时保存数据快照，新增事件不会改写旧报告；点击“按最新记录重新生成”才更新版本。脱敏长图输出实际临时 PNG，保存只有平台成功回调才提示成功。
- **家庭与账号**：按角色限制危险操作；创建/绑定/解绑/转移/更正/删除查询任务最终结果。切换孩子、退出或重置后，旧任务不能写回新会话。
- **玩机指南**：点击展开具体步骤，再进入对应功能，不再把“指南”直接当普通跳转列表。
- **视觉**：沿用家长操作界面，适配海蓝/青蓝/白色与少量金色；修复顶部胶囊遮挡、组件告警和状态显示。

## 成长计算口径

六维为：系统认知、数据与感知、网络与控制、AI理解、工程创造、人本安全。界面称“六维探索覆盖”，**不是能力分数、人格评价或排名**。

映射依据 V3.1 正式内容矩阵；演示计划为 28 项共同内容，加上对应年龄的一项综合任务，每名孩子固定 29 项。Web 关卡映射仍是独立演示映射，不代表正式平台已开放接口。

覆盖率 = 该维度相关且已完成的内容数 ÷ 演示计划中相关内容总数。小满初始为 4/29，星河为 1/29。可通过体验设置注入 B04，观察首页与成长同步变化、重复注入不重复计数；历史报告需重新生成。

## 测试与使用说明

只依赖 Node.js 内置测试能力，不需安装第三方 npm 包：

```sh
npm run verify
git diff --check
```

当前检查包括 46 页四件套、语法、事件/路由/组件/资源、组件选择器限制、敏感信息及行为测试。46 页都有至少一个直接控制器测试，但这不代表全部按钮/异常分支/机型都完成了人工验收。最终数字和剩余问题以质量报告为准。
