# AILab 微信小程序家长端

微信原生 JavaScript / WXML / WXSS，四个一级入口：**首页｜守护｜成长｜我的**。

当前默认是可操作、可保存本地状态的功能模拟版本。已增加**定位、语音和视频的客户端接入层、云托管后台及微信通话适配代码**，但厂家接口、正式关系、插件授权和样机尚未接入。界面明确区分演示/设备接入模式，真实模式配置不足会阻断，不回退为模拟成功。

## 本轮重点改进

- **首页**：陪伴概览、待办、按日期排列的动态、类型筛选、兴趣足迹及只读成果；累计数据不再被称作“今日”数据。
- **守护**：map 组件呈现模拟当前点位；定位过期、离线及解绑清坐标。保留语音、新增视频及双向模拟画面；接入模式提供后台鉴权、真实有效期、订阅清理、刷新任务、会话恢复和官方通话页适配。其余设备工具继续演示，不扩展真实接入范围。
- **成长**：从同一批探索事件生成进度、六维、维度依据和成果。解锁不算完成，重复完成不重复计数；数据未知与已知 0% 区分展示。
- **报告**：生成时保存数据快照，新增事件不会改写旧报告；点击“按最新记录重新生成”才更新版本。脱敏长图输出实际临时 PNG，保存只有平台成功回调才提示成功。
- **家庭与账号**：按角色限制危险操作；创建/绑定/解绑/转移/更正/删除查询任务最终结果。切换孩子、退出或重置后，旧任务不能写回新会话。
- **玩机指南**：点击展开具体步骤，再进入对应功能，不再把“指南”直接当普通跳转列表。
- **视觉**：沿用家长操作界面，适配海蓝/青蓝/白色与少量金色；修复顶部胶囊遮挡、组件告警和状态显示。

## 测试与使用说明

### 小程序与联调台配对（2026-10-02）

已新增 **TCP 接收 → 本机 HTTP 桥 → 守护地图**，以及小程序与联调台共用编号的语音 / 视频信令模拟。仅在本台 Mac 的微信开发者工具运行；不绑定真实孩子、不传真实音视频、不向公网开放网页。详细操作、待硬件提供资料及 188 项测试结果见 [小程序本机联调](docs/MINI-LOCAL-LAB.md)。

以下为旧 TCP 台操作：打开联调台 → 选择测试连接 / 坐标系 → 生成配对码 → 在小程序“体验设置”输入 → 返回守护。是否已启动需检查本机进程；不要假定它始终常驻。公网测试必须另行明确授权，不在本轮范围内。

### 本机接收 mini 定位数据（2026-09-30 新增）

硬件已提供 `经度_纬度` 格式。本机 TCP 接收工具位于 `tools/mini-location-tcp/`，不改变默认演示模式、不部署云端服务；只有完成上述显式配对后才向开发者工具输出联调点位。

```sh
npm run device:tcp
# 保持上面的终端运行，在另一个终端发送合成测试数据：
npm run device:tcp:send
```

也可以双击 `tools/mini-location-tcp/启动接收程序.command`。默认仅监听 `127.0.0.1:18765`，不是公网地址。没有换行的固件可先使用 `npm run device:tcp:probe` 排查，候选数据不算正式定位。

临时公网联调使用 `启动远程测试.command`（与独立接收程序二选一），只用于合成坐标；组合工具自动启动接收与 Pinggy TCP 穿透，最多 55 分钟后关闭，不自动重连。用 `停止远程测试.command` 提前关闭。每次公网地址可能变化；真实位置须先确认端到端加密和设备认证，不使用当前裸 TCP 测试入口。

完整操作及给硬件方的消息见 [本机定位接收与联调说明](docs/MINI-LOCATION-TCP-TEST.md)。

## 微信云托管接入准备（2026-10-10）

已备独立 Node.js 设备后台和 `callContainer` 客户端适配，规划新服务 `ailab-device-gateway`，不覆盖当前 Django 官方计数模板。环境 ID 已记录，默认 demo、未启用连接、不启用真实媒体。旧云函数接入方式保留。

完整操作、私有网关安全边界、可选 MySQL 持久化、部署前置条件见 [云托管接入说明](docs/CLOUDRUN-INTEGRATION.md)。本轮不部署、不上传、不修改现有云服务，也不证明云端或硬件已接通。此处是新云托管路线的说明；原 TiRTC 文档中的 CloudBase 云函数路线继续保留为另一种选择。
