让本机适配程序使用 media-send.js，把脱敏会话编号、来源、递增序号、状态和网络指标传入监控接口。接收地址仅在这台电脑可用，不是设备公网接口。

云端服务不能直接访问这里；需另行接入经过认证的本机桥接程序。只监控元数据，不传 Token、SDP、音视频内容、手机号或真实设备序列号。

房间创建不是接通。窗口分别展示孩子接听、媒体就绪、视频就绪等上报标记；这些标记本身不能替代真实样机验证。
