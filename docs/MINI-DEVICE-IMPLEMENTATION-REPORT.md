## 4. 微信开发者工具回归

环境：微信开发者工具 Stable 2.02.2608060，基础库配置 3.17.2，iPhone 12/13 模拟器。当前窗口 AppID 与项目配置一致。未据此确认账号上传权限。

| 手工路径 | 观察结果 |
|---|---|
| 守护 → 视频通话 → 呼叫 | 进入等待，再到“已接通 · 演示”；设备插画及家长占位明确不是摄像头画面 |
| 视频关闭画面、静音 | 画面关闭提示与静音选中态同步变化 |
| 返回守护 → 重进视频 | 恢复原会话、原时长、静音及关闭画面状态，没有自动重拨 |
| 视频结束 | 状态变为已结束，时长停止，可重新呼叫 |
| 守护位置过期 → 刷新 | 原坐标与旧地址不显示；刷新后出现新的模拟点位、采集时间及结果说明 |
| 重新编译 → 守护 → 语音呼叫 | 正常进入语音演示接通状态，不被旧视频类型覆盖 |
| 语音结束 | 正常结束，保留本次结果，不继续计时 |

控制台观察到 0 运行错误；存在开发者工具热重载、资源 preload 和 worker `reportRealtimeAction:fail not support` 提示，未宣称平台警告清零。连续保存时曾出现热重载页面停留在加载态，完整重新编译/重进后恢复，因此最终正常链路按重新编译后的结果记录。

本轮没有对其他 46 页所有按钮重做一遍真机验收；原自动回归全部保留。iOS/Android 实际插件页面、摄像头/麦克风授权、样机定位和双向媒体均未验证。

## 6. 部署前安全门槛

对新增云函数依赖执行了 npm 审计。最初的旧 SDK 依赖问题较多，已改用查询时最新的 `wx-server-sdk@4.0.2` 并锁定依赖；但官方依赖链仍有 **6 个审计警报：5 高、1 中、0 严重**。

底层涉及 `axios@0.27.2`、`lodash.set@4.3.2`、`lodash.unset@4.5.2`，其上层 CloudBase/微信包被连带标记。它们是依赖链计数，不是六个已证实可利用的本项目漏洞，但不能忽略。

本轮没有为了清空数字强行替换 SDK 的内部依赖或按自动建议降级至旧版。上线前需选用上游修复版或经过接口、数据库事务、HTTP 行为和真云环境测试的补丁方案，再执行审计。本轮未部署，因此没有把这些依赖引入正在运行的线上服务。

官方包版本与依赖可查：[wx-server-sdk](https://www.npmjs.com/package/wx-server-sdk)。审计不是完整渗透测试，也不能替代正式儿童信息保护与平台隐私评估。
