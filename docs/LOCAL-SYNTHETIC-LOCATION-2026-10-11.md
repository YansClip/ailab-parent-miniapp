# 本机模拟定位：使用步骤与验证记录

日期：2026-10-11。仅测试数据，不是正式定位验收。

## 这次完成了什么

新增两个相互配合的入口：

1. **电脑浏览器的模拟定位台**：发送固定的虚构位置 A/B，模拟无定位、离线、过期和本机权限变化。
2. **微信开发者工具里的独立测试页**：通过本机接口查询结果，验证点位更新与清除。

本次链路是：预设报文 → 本机签名 HTTP 接收 → 临时内存 → 后台权限查询 → 测试页面。

复用已有后台的定位报文校验、签名鉴权、绑定版本核验、过期清理和位置查询逻辑；不是只换页面文案。但存储特意改为临时内存，不连接 MySQL，不依赖真实微信身份。

不测试真实硬件、TCP 连网、地图服务、手机 GPS、云端写入或真实音视频。独立测试设备名为「本机模拟设备 S」，绑定版本 1，与云端「虚构测试设备 A / 绑定版本 3」无关。

## 第一次怎么操作

### 1. 打开电脑测试台

本次已由 Codex 启动。本台电脑浏览器打开：

http://127.0.0.1:18868

若重启电脑或工具已停止，双击项目中的 `tools/synthetic-location-lab/启动模拟定位.command`。也可以在项目目录运行：

```sh
npm run device:location:lab
```

看到「本机模拟定位台」启动提示后再打开网页。端口被占用时不要结束不认识的进程，也不要重复启动；先确认是否已有该测试台在运行。

### 2. 打开开发者工具中的测试页

项目目录：`/Users/sc/WeChatProjects/miniprogram-1`。

只需本地编译，不点上传、预览或真机调试。

模拟器中：**我的 → 关于我们 → 长按上方 AILab 家长端/版本区域 → 体验设置 → 打开独立定位测试页**。

若入口没出现，点击开发者工具的本地「编译」后重新进入。

### 3. 配对

1. 电脑网页向下找到「连接独立测试页」，点「生成新配对码」。
2. 把网页上的 10 位配对码填到小程序测试页中。
3. 点「配对并只读查看」。成功后输入区域消失，出现「在电脑控制台切换场景」。

配对码 5 分钟有效且只能用一次；会话 30 分钟有效。离开小程序测试页会清空本地配对和坐标，返回后重新生成配对码即可。配对码只用于本机临时查看，不是数据库密码或设备密钥。

### 4. 按顺序测试

| 电脑网页上点击 | 小程序测试页应看到 |
| --- | --- |
| 发送位置 A | 点 A，120.0001 / 30.0001，最多 15 秒有效 |
| 发送位置 B | 点 B，120.0004 / 30.0003 |
| 设备无定位 | 「尚未取得位置」，点消失，坐标为 — / — |
| 发送位置 A，再点设备离线 | 「模拟设备离线」，点与旧坐标清除 |
| 发送位置 A，再点模拟过期 | 「模拟位置已过期」，旧点清除 |
| 发送位置 A，再点撤回查看权限 | 「查看权限已撤回」，不返回位置 |
| 恢复查看权限，再发送位置 A | 再次出现有效点 A |
| 另一虚构账号 | 回执显示未授权账号被拒绝；当前查看账号不切换 |
| 错误签名上报 | 回执显示拒绝，没有新位置写入 |
| 不匹配的绑定版本上报 | 回执显示绑定版本不匹配，没有新位置写入 |

小程序每 2 秒查询一次，可点击「立即重新查询」。位置过期在客户端也有独立计时，不依赖下一次请求成功。没有自动续发坐标，因此操作慢时点自然消失是正常现象；再点一次 A/B 即可。

「模拟过期」只推进本工具的测试时钟，不修改电脑时钟、云端时间或配对期限。示意板不是地图，不展示真实地址或保存轨迹。

## 如果连接失败

- 浏览器打不开：确认本机工具仍在运行；当前仅监听 127.0.0.1:18868。
- 配对码失效：网页点「生成新配对码」，再输入。
- 小程序提示本地网络访问被限制：把错误提示交给开发人员检查；不要去修改云端域名、数据库外网或云端权限。本次实测使用项目原有的本地调试设置，没有修改网络安全开关。
- 手机无法连接：这是预期行为。手机、体验版、正式版和其他 AppID 均会在发出请求前拒绝本机模拟连接。当前不上传新体验版。
- 出现网络错误：点和旧坐标会清空，不会伪装连接成功或切换到云端。
- 工具停止或重启：网页会显示「重新连接工具」。确认工具已启动后点击它，再生成新的配对码；旧会话不会自动续用。
- 小程序配对会话到期：会清空点位、恢复配对输入区。重新生成配对码即可；请求没有回调时也会在 5 秒后中止，不会一直卡住。

## 如何停止

小程序点击「断开本机测试」后，在运行工具的终端按 Control+C。若是 Codex 启动的且你找不到终端，可以让 Codex 帮你停止。本次临时数据会清空；已有云端数据和其他联调服务不受影响。
