# V3 本地演示与验收走查

适用范围：当前仓库的微信原生小程序、`services/api.js` 门面及本地模拟服务。本文依据 2026-09-12 当前代码整理，是可重复的走查说明，不代表所有条目均已完成真机验证。

所有家庭、孩子、探索事件、设备状态和业务任务保存在当前小程序的本机缓存。设备通话、响铃、定位点、消息提醒、客服反馈与后台任务均不是已接通的真实服务。PNG 生成、图片预览和相册保存则调用微信本地图片能力，仍受当前设备与用户权限限制。

## 1. 首次进入与绑定

1. 从欢迎页选择“开始使用”，阅读并同意隐私规则，再点击微信登录。
2. 登录必须取得 `wx.login` 的成功结果且含 `code`；取消、失败或没有 code 都不应进入已登录状态。本版尚未把 code 发送到真实账号后端。
3. 创建家庭时填写家庭名称和家长称谓；也可通过“加入已有家庭”进入绑定。
4. 输入下表的测试绑定码，提交后进入等待页。必须查询到任务 `success` 并通过 `completeBind(taskId)` 校验，才进入绑定成功页。
5. 进入首页，确认当前孩子姓名、年龄与设备；首页或成长页可切换当前家庭提供的两个示例孩子。本版预置关系用于模拟，不是对真实家庭成员关系的核验。

| 输入 | 当前服务结果 | 建议用途 |
|---|---|---|
| `222222` | 小满，11 岁，`child-xiaoman`，Mini 01 | 主流程；初始设备在线 |
| `333333` | 星河，14 岁，`child-xinghe`，Mini 02 | 第二主体；初始设备离线 |
| `123456` / `654321` | 分别为上面两名孩子的兼容测试码 | 兼容旧走查；不是任意六位数字都能绑定 |
| `000000` | 过期；`BIND_CODE_EXPIRED` | 页面先拦截并提示重新获取 |
| `111111` | 已使用；`BIND_CODE_USED` | 页面先拦截 |
| 已成功使用过的测试码 | `BIND_CODE_USED` | 验证一次性码；未重置前不能重复使用 |
| 其他六位数字，例如 `999999` | `BIND_CODE_INVALID` | 验证服务错误提示 |
| 少于六位或含非数字 | 页面校验失败 | 不应发起绑定任务 |

扫码只接受六位数字，或 `ailab:bind:222222` 这样的完整格式。取消扫码不应报业务失败；相机权限问题保留手动输入入口。

## 2. 隐藏体验设置

入口：**我的 → 关于我们 → 长按顶部“AILab 家长端”品牌区**。进入的是 `pages/my/debug`，普通家长页面不展示场景切换器。

场景选项作用于当前本地演示环境，部分操作会改变当前孩子的持久化状态。切回 `default` 只是取消异常场景，不等于撤销之前的解绑、数据删除、管理员转移或内容注入。

| 实际场景 ID | 入口 | 走查重点与恢复 |
|---|---|---|
| `default` | 页面 | 默认请求行为；小满初始在线、星河初始离线，不是强制所有设备在线 |
| `empty` | 页面 | 隐藏探索事件输入，首页/成长显示不足或空态；切回正常可恢复原数据，它不是删除操作 |
| `loading` | 页面 | 普通请求约延迟 1.2 秒；查看骨架、重复点击和快速切孩子是否串数据 |
| `offline` | 页面 | 模拟网络请求失败，返回 `OFFLINE`；体验设置本身使用本地通道，可切回正常 |
| `device-offline` | 页面 | 设备离线：不显示有效坐标，不能通话/响铃；联系人、闹钟、SOS 可按权限保存为待同步 |
| `stale` | 页面 | 当前孩子位置过期，无有效坐标；在线设备点击刷新后可取得新的模拟位置 |
| `call-busy` | 页面 | 发起一通新通话后进入占线状态 |
| `call-rejected` | 页面 | 发起一通新通话后进入被拒绝状态 |
| `call-interrupted` | 服务支持，页面未列出 | 约 1.8 秒接通，约 7 秒后中断；见下方开发者工具入口 |
| `timeout` | 页面 | 普通任务约 1.8 秒出现超时，约 5 秒后可查询到最终结果；通话约 8 秒超时；不要把等待超时当成已取消 |
| `fail` | 页面 | 新提交任务或新通话失败；原业务数据不应提前变更；切回正常后重新提交 |
| `device-online` | 页面 | 将当前孩子的设备设为在线，并在后续查询中完成本地待同步配置；已解绑设备不会因此自动重新绑定 |
| `generating` | 页面 | 为当前有数据的孩子提交周报和阶段报告生成任务，观察生成中、离页重进和完成后重读 |

开发者工具中，仅需补测未列出的中断场景时，可在当前小程序 Console 调用：

```js
getApp().api.setDemoScenario('call-interrupted')
```

这不是生产后台入口。完成后在体验设置切回正常；测试新通话前先结束上一次未结束的会话。服务的时间推进发生在查询时，不依赖一个真实运行的设备端或云端定时器。

## 3. 推荐的一轮验收顺序

| 顺序 | 操作 | 应查看的结果 |
|---|---|---|
| 1 | 正常场景进入首页，点动态、探索完成摘要、待办 | 都进入有效页面；处理家庭邀请后返回，待办数量重新读取 |
| 2 | 小满、星河来回切换 | 姓名、设备、探索记录、联系人、闹钟和报告以当前孩子为准；不得显示上个孩子的晚回包 |
| 3 | 打开兴趣足迹并关注，再返回重进 | 关注状态持久化；无公开点赞、排名或照片分享 |
| 4 | 进入成长六维及维度详情 | 标题为探索覆盖；比例有已完成/相关总数及来源依据，不是能力打分 |
| 5 | 成长启思简报选择已有日期记录，查看关联事件 | 日期、主题、摘要、验证记录匹配同一事件；没有数据时不补造正文 |
| 6 | 离线场景保存闹钟或联系人，再恢复在线 | 先显示“已保存、待同步”，再次查询后显示已同步；不能把离线保存当作设备已执行 |
| 7 | 通话/查找设备，离开再进入，手动停止 | 状态来自会话查询；查找最长 60 秒；离开页面不产生第二个并发会话 |
| 8 | 分别打开成长报告与成果的脱敏长图 | 内容必须对应各自目标；PNG 真实生成后才允许打开或保存 |
| 9 | 相册授权拒绝、取消或失败 | 不提示已保存；保留已有预览；真正调用成功回调才提示保存成功 |
| 10 | 最后测试权限转移、解绑、删除、撤回与注销 | 阅读影响范围、确认后提交、查询最终结果，再按第 6 节恢复 |

位置过期窗口为 5 分钟，页面仅显示当前有效位置，不提供历史轨迹。没有真实时长事件时，首页不展示“0 分钟陪伴”；当前摘要采用可追溯的探索完成数。

## 4. 用 B04 验证探索完成与去重

先选择小满，并在需要时重置示例数据。小满初始已完成 **B01、B02、B03、S01**，总进度应为 **4/29，四舍五入 14%**；星河初始为 **1/29**。

体验设置输入框当前默认是 **B02**，但 B02 已完成，直接点击不会让小满增加进度。要演示“新增完成”，请主动改成 **B04**：

1. 如需同时比较旧报告，先在成长页打开周报和阶段报告，记录生成时间与报告内容；版本可在开发者工具通过 `getApp().api.getReport('w1')` 返回结果查看。
2. 进入体验设置，将编号改为 `B04`，点击“模拟完成”。
3. 返回首页/成长：小满应增加到 **5/29，四舍五入 17%**；能看到对应完成记录。B04 正式标题为“让系统可控：规则、状态、反馈与失效安全”。
4. B04 映射系统认知、数据与感知、工程创造、人本安全；这四项相关覆盖变化，网络与控制、AI 理解不因 B04 增加。
5. 再次注入同一 B04：返回重复记录提示，完成数和六维覆盖不应再次增加。即使换一个事件 ID，同一孩子的同一内容首次完成也只计一次。
6. 切到星河，不能看到小满刚注入的 B04 完成记录。若要测试星河，必须明确切到星河再注入。

隐藏页面只提供完成事件按钮。开发者工具补测“解锁不等于完成”时可使用：

```js
getApp().api.injectDemoEvent({
  id: 'qa-unlock-T01',
  type: 'course-unlocked',
  courseId: 'T01'
})
```

该事件可以改变解锁状态，但不增加 `progress.completed` 或六维的已完成分子。这些注入不代表孩子实际完成了 Web 课程、题目或项目，仅用于模拟展示与验收。

## 5. 报告再生成与失败恢复

周报 ID 为 `w1`，阶段报告 ID 为 `p1`。报告使用生成时的快照，含截止时间、事件依据与版本；新增探索事件不应悄悄改写已经生成的历史快照。

- 从体验设置选择 `generating`，会给当前孩子的两份报告提交再生成任务。进入报告可显示生成中并轮询；普通成功任务约 1.8 秒后可查询为 `success`。
- 页面必须在任务成功后重新 `getReport(id)`，不能只把页面状态改成 ready。核对版本以及新快照是否包含 B04。页面生成时间只显示到分钟，同一分钟再生成时文字可能相同，应以返回的 version 和 snapshot.cutoffAt 辅助核对。
- 离开页面再回来也应能重新查询已完成结果。查询驱动的本地状态恢复不等于真实后台一直在运行。
- 要覆盖“生成失败”而不是仅网络失败，先切到 `fail`，再在开发者工具提交：

```js
getApp().api.regenerateReport('w1')
```

随后打开周报查询失败结果；切回 `default`，在报告失败页点“重新生成”。`timeout` 场景先查询原任务，确认最终状态，再决定是否重试，避免把同一个动作重复提交。

## 6. 权限、删除、注销与恢复

高风险场景放在验收最后，避免影响前面的基线。

| 操作 | 本版实际影响 | 如何恢复演示 |
|---|---|---|
| 切回 `default` | 仅切换场景 | 不恢复已修改的数据 |
| 体验设置“重置本地示例数据” | 清本地业务缓存、任务、关注等；恢复默认示例家长、称谓、家庭名称、主管理员，切回小满和正常场景；epoch 递增，旧任务失效 | 保留已有登录/隐私同意布尔值；只有两者都为 true 才恢复 familyCreated/familyReady，不会代替未登录用户授权 |
| 转移主管理员 | 当前用户变普通成员；管理按钮与服务写权限受限 | 仍已登录时可在体验设置重置，恢复示例主管理员；若设置页不可达，按下方完整恢复流程操作 |
| 解绑设备/孩子 | 当前关联失效，设备工具受限；至少保留一名孩子 | 使用有效绑定码或已关联设备的恢复入口；重置也可恢复本地示例关联 |
| 删除互动数据 | 清当前孩子事件、报告、成果及关注；保留家庭/设备关系与其他孩子记录 | 如要恢复初始演示，使用体验设置重置；不是删除真实 SaaS 数据 |
| 撤回同意 | 本机隐私同意及登录失效，旧任务取消 | 返回欢迎页重新同意并登录；真实同意记录未接后台 |
| 本地账号注销 | 本机隐私/登录失效、familyReady 变为 false、旧任务失效；不注销真实微信或 AILab 账号 | 返回欢迎页后重新同意、登录；完整恢复见下方 |

**完整恢复新手流程：**

1. 仍能进入“我的 → 账号设置”时，执行“退出登录”，再从欢迎页重走流程。当前 `store.logout()` 会清理本地示例业务缓存并恢复默认 session。
2. 注销、撤回或权限变化后无法到达设置页时，在微信开发者工具清除**当前小程序**的数据缓存，然后重新编译，从欢迎页开始；不要清除其他项目或无关文件。
3. 恢复后可重新使用 `222222` / `333333`。若只是重新登录而没有清理业务缓存，曾成功使用的绑定码仍可能显示“已使用”，这不表示随机输入新码就能绑定。
4. `resetDemo()` 要求已有登录和隐私同意；注销后不能直接调用它绕过登录。如果仅希望开发者工具内完整恢复当前示例，可使用公开到 App 的本地 store，再重启欢迎页：

```js
getApp().store.logout()
wx.reLaunch({ url: '/pages/auth/welcome' })
```

以上恢复会移除本机示例操作，无法替代真实后台的数据恢复、账号恢复或监护关系重建。

## 7. 记录验收证据

每条记录建议包含：日期、代码提交号、开发者工具/真机型号、当前孩子、场景 ID、操作、期望、实际、截图或任务 ID。不要在证据中记录真实儿童姓名、手机号或精确位置。

- `npm run check`：注册、语法、路由、事件绑定和资源静态检查。
- `npm test`：服务、权限、会话、成长映射与页面数据行为测试。
- 两者通过只说明对应自动检查通过，不代表真实设备、音频、定位、订阅通知、相册授权或全机型安全区均已验证。
