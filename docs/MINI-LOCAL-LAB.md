# 小程序 × mini 本机联调

更新：2026-10-02。适用：当前 Mac、微信开发者工具及本机设备联调台。

## 现在能做什么

| 功能 | 当前结果 | 还不代表什么 |
|---|---|---|
| 定位 | TCP 上报 → 本机接收 → 小程序守护地图，支持更新、断开清点和坐标转换 | 未认证设备身份；没有实际采集时间、精度、电量及正式绑定 |
| 语音 / 视频 | 小程序发起测试会话，在联调台推进响铃、接听、连接、中断或挂断，两边共用同一个编号 | 仅信令状态模拟，不传声音、画面，不调用设备摄像头或麦克风 |
| 正式接入检查 | 体验设置列出云环境、微信插件、厂家 SDK / 型号许可及回调的缺项 | 配置检查不是微信授权、部署或真机验收 |

本机联调与默认演示、CloudBase 接入是三种独立模式。配对失败或本机服务不可用时不会回退成演示成功。本轮未部署、上传、推送或修改飞书 / Figma。

## 你怎么使用

### 1. 打开联调台

浏览器打开 **http://127.0.0.1:18866/**。当前 Mac 已有后台常驻服务，不需要额外开一个接收终端；若服务未运行，双击 `tools/mini-location-tcp/启动接收程序.command`。

先确认“接收已开启”。需要远程 TCP 测试时仍使用已有公网按钮；**不要公开 18866 网页端口**。本轮没有开启公网。公网未经设备认证与端到端加密确认，仅允许合成坐标。

### 2. 让小程序配对

1. 在联调台的“小程序本机联调”选中本次测试连接，例如 `C1`；必须由你明确选择，不会根据 IMEI、IP 或历史连接猜测孩子。
2. 选择**实际上传值**的坐标系。按硬件工程师已确认的原始 GNSS 数据选 WGS84；若固件已转换则选 GCJ-02。未知就保留“未确认”，此时不会显示地图。
3. 点击“生成配对码”。配对码 5 分钟内有效、仅用一次，**只在本机小程序输入，不发给硬件工程师**。
4. 开发者工具右上角编译模式可选“本机联调设置”（启动页 `pages/my/debug`）；或正常进入“我的 → 关于我们 → 长按顶部 AILab 标识 → 体验设置”。若私有配置覆盖了模式列表，通过“添加编译模式”填入上述页面路径。
5. 输入 10 位配对码，点“配对本机联调台”，返回首页，再进入“守护”。首次使用仍需完成本地示例的隐私和登录流程；这不产生正式家庭授权。

只支持 AppID `wxc5abf3407ed4ef30` 的 **develop 版 / devtools 平台**。手机真机、体验版和正式版会拒绝本机联调。会话最多 30 分钟；重新编译 / 重启小程序后需重新配对，凭证只在内存。重新生成配对码会撤销旧配对。

本机现有 `project.private.config.json` 已关闭开发工具域名校验，本轮没有改动该安全选项。共享配置仍保留 `urlCheck: true`。本机 HTTP 调试通过**不等于**正式 HTTPS、域名白名单、真机网络通过；不要为生产环境关闭安全校验。

### 3. 看定位

- 新报文自动更新点位。页面显示“联调点位（未认证）”及“本机接收时间”，不把接收时间当设备采集时间。
- 设备实际采集时间、精度、电量未知时如实显示未知，不编造值。
- 点击“等待下一次上报”后，必须收到所选连接的一条新报文才结束等待；**并未向设备下发强制定位指令**。20 秒未收到则超时。
- 30 秒无新上报、TCP 断开、配对失效时清除点位；30 秒仅是本机展示限制，不是正式定位有效期约定。
- TCP 重连后是新连接，需要重新选择和配对，不自动接入其他来源。离开守护页停止轮询；返回后查询当前状态。

硬件继续按已确认格式发送 `经度_纬度`，末尾是真正的 `\r\n`，本机不回复。小程序不直连裸 TCP，而是通过本机 HTTP 桥读取数据。

没有硬件时，可在项目终端启动 **合成坐标**长连接：

```sh
npm run device:tcp:send -- --scenario stream --seconds 300
```

每 3 秒一条，5 分钟后停止，Ctrl+C 可提前结束。然后在网页选择该连接并配对。它不是硬件上报证据。网页原有“发送一次”会迅速断开，不适合持续地图联调。

### 4. 练习音视频状态联调

1. 小程序“守护 → 语音通话 / 视频通话 → 发起本机信令模拟”。
2. 网页切到“音视频通话”，使用 **“来自小程序的信令模拟”** 这组按钮。
3. 依次点“模拟响铃 → 模拟接听 → 模拟连接成功”，小程序同步变化并显示模拟时长。
4. 可点拒接、忙线、失败、离线、中断或设备挂断；也可从小程序点“结束通话”，网页同步结束。
5. 返回后重进会恢复原会话，不自动重拨；结束后才能新建其他类型会话。没有接通时 30 秒超时，模拟接通最长 10 分钟。

网页原有“跑一遍模拟流程”是**独立自测**，不驱动小程序这次会话。请认准相同 `lab-…` 编号。监控中的接听 / 媒体就绪标记仍为“未确认”，不能把人工推进状态当真实孩子同意或真实媒体建立。

### 5. 结束测试

- 在小程序体验设置点“退出本机联调”，恢复原配置模式；或在网页点“断开小程序配对”，小程序会提示配对失效，不回退演示点位。
- 退出账号、撤回同意或重置本地示例会撤销本机凭证并尝试结束会话。
- 停止合成数据流，关闭不再使用的公网入口。后台接收可继续运行；电脑睡眠 / 关机时不能保证在线。

## 开发者接入位置

| 文件 | 职责 |
|---|---|
| `tools/mini-location-tcp/lab-bridge.js` | 配对、固定连接、当前点位转换、刷新等待、共享模拟会话 |
| `tools/mini-location-tcp/monitor.js` | 只监听 loopback 的 HTTP 路由；网页与小程序凭证分离 |
| `tools/mini-location-tcp/monitor-ui/` | 来源选择、配对和手动推进会话 |
| `miniprogram/services/device/lab.js` | 开发工具专用传输、内存凭证、取消及响应乱序保护 |
| `miniprogram/services/device/index.js` / `services/api.js` | 三种模式的统一入口，失败不串用数据来源 |
| `miniprogram/pages/guard/` / `pages/my/debug.*` | 定位、通话展示及配对操作 |

HTTP 基址固定 `http://127.0.0.1:18866/lab/v1/`，JSON POST。配对后通过 `x-lab-token` 调用 `snapshot / watch / unwatch / refresh / call.start / call.get / call.end / disconnect`。返回 `{ok,data,serverTime}`，失败返回 `{ok:false,error:{code,message}}`；HTTP 400/429 不得当成功。它是内部联调协议，不是厂家正式协议。

小程序凭证无权控制公网、接收开关或报文原文。Host / Origin 检查、5 分钟一次性配对、配对尝试限流、30 分钟会话有效期及取消标记用于隔离本机测试；不能替代正式身份鉴权。凭证、精确坐标不写本地存储或普通日志。

## 下一次和硬件方确认什么

| 定位 | 音视频 |
|---|---|
| 可认证的设备 ID / 绑定关系，而非只发经纬度 | 设备系统、芯片、选用 SDK 和型号许可 |
| 坐标系、十进制度、采集时间、精度 / 有效标记 | 邀请、设备接听 / 拒接、双方媒体就绪及结束事件 |
| 上报频率、序号、断线重连、设备在线及电量 | `callId`、媒体类型、事件序号、错误码及回调鉴权 |
| 是否支持刷新指令、指令 ID 和执行结果 | 微信插件 / 云对云方式与真实样机双向测试 |
| 真实位置的认证、TLS 与正式 HTTPS 后台 | 不远程监听、不绕过孩子接听、不录音录像 |

在上述能力明确前，继续用合成坐标和信令模拟；不要声称“真实定位业务已验收”或“音视频已接通”。正式接入步骤仍见 [mini 设备接入说明](MINI-DEVICE-INTEGRATION.md)。
