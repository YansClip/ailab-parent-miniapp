# AILab 微信小程序甲方提供与确认清单

> 版本：2026-08-29  
> 用途：项目启动、开发联调、工信部备案、微信审核与正式发布前的甲方资料收集和决策确认。  
> 产品范围：AILab 微信小程序家长端，一级入口为“首页｜守护｜成长｜我的”。

## 1. 使用说明

变更代价分为四级：

| 等级 | 含义 | 常见影响 |
|---|---|---|
| 低 | 一般设置或素材替换 | 约 0.5–2 个工作日，通常不改业务逻辑 |
| 中 | 需平台审核、代码调整或重新提审 | 约 2–7 个工作日，可能影响发布计划 |
| 高 | 需资质、重新认证、备案变更或跨系统改造 | 常见 1–4 周，可能产生平台费用和重新验收 |
| 极高 | 更换主体、AppID 或核心服务路线 | 可能需新账号、迁移用户/数据、重新备案和审核 |

**安全要求：**身份证、营业执照原件照片、AppSecret、上传密钥和生产 Token 不得写入本清单、群聊或代码仓库；甲方应通过受控网盘、密码管理器或平台权限直接授权。

## 2. 项目启动前必须确认（P0）

| 编号 | 甲方需提供/确认 | 具体要求与完成证据 | 最晚时点 | 变更代价 |
|---|---|---|---|---|
| A01 | 运营主体 | 确认使用的企业法定全称、统一社会信用代码、注册地址，与营业执照一致 | 注册账号前 | **极高**；不应用开发者个人或乙方公司作为主体 |
| A02 | 主体证件 | 营业执照彩色扫描/原件照片，证件在有效期内，边框完整 | 注册/备案前 | 高；证件变更后需同步平台与备案 |
| A03 | 法定代表人 | 姓名、证件类型/有效期、本人手机、邮箱，能配合短信、扫码或人脸核验 | 注册/备案前 | 高；浙江等地备案主体负责人通常要求为法定代表人 |
| A04 | 小程序管理员 | 指定一名甲方长期在职人员；提供姓名、微信号、手机、邮箱，负责扫码和上线授权 | 账号创建时 | 高；原管理员离职/失联会影响授权和发布 |
| A05 | 备份管理联系人 | 指定一名备份负责人，保存主体资料、账号归属和紧急申诉流程 | 项目启动时 | 中；可降低单人锁定风险 |
| A06 | 注册邮箱 | 甲方企业可长期控制的专用邮箱，不使用个人开发者邮箱 | 账号创建时 | 高；丢失会影响登录和找回 |
| A07 | 注册路径 | 确认“新注册企业小程序”还是“从同主体已认证公众号复用资质” | 注册前 | 中高；影响认证、主体与权限路径 |
| A08 | 小程序名称 | 提供 3–5 个按优先级排序的候选名称，确认是否使用 AILab/链境品牌词 | 注册前 | **高**；详见第 8 节 |
| A09 | 品牌权利 | 提供商标注册证/申请受理材料或品牌授权书；确认 Logo、产品名和角色素材的权利归属 | 名称/头像提交前 | 高；缺失可导致名称驳回或侵权投诉 |
| A10 | 核心业务边界 | 确认小程序是家长端；有首页、守护、成长、我的；不含支付、商城、社区 UGC、历史轨迹等未规划能力 | 开发启动前 | 高；会联动类目、隐私、代码和审核 |
| A11 | 真实能力路线 | 确认实时位置、语音通话、查找设备、通讯录、闹钟与紧急联系人哪些由正式硬件/设备云支持 | 技术方案冻结前 | **极高**；影响是否可上线为真实功能 |
| A12 | 数据主体与存储 | 确认 SaaS、小程序后台、设备云各自保存什么，服务器地域、保留期、删除责任人 | 接口冻结前 | 高；后改会涉及迁移、隐私和备案 |

## 3. 小程序品牌与对外信息（P0）

| 项目 | 甲方需确认/交付 | 建议交付格式 | 变更代价 |
|---|---|---|---|
| 小程序正式名称 | 最终名称＋3–5 个备选；明确是否带“家长端”“守护”等后缀 | Word/飞书文本，标注优先级 | 高；发布后企业主体通常需走微信认证改名 |
| 简称 | 确认是否需要，与正式名称有明确关联 | 中文简称＋英文缩写 | 中；修改/删除可能占用平台额度 |
| 小程序头像 | 甲方批准的正式 Logo，不含二维码、电话、红点、“官方”等误导元素 | 1024×1024 PNG 源文件，并输出 144×144 预览；保留四周安全区 | 中；受平台修改额度与审核约束 |
| 功能介绍 | 用户可理解的简介，不宣称尚未接通的真实定位/语音能力 | 提供 3 版：简短、标准、审核备用 | 中；常见限额为每月 5 次，以后台实时计数为准 |
| 服务类目 | 甲方、产品、合规及技术联合选择；必须与真实功能一致 | 后台可选类目截图＋选择理由＋所需资质 | 高；类目错误会直接导致审核驳回 |
| 服务标签/搜索词 | 确认品牌、智能硬件、家庭陪伴、成长等用词 | 不使用误导、夸大、未上线功能 | 低至中 |
| 分享标题与分享图 | 默认分享文案，成长报告是否允许分享及脱敏规则 | PNG/JPG 及可编辑源文件 | 中；涉及儿童信息时需重新做隐私检查 |
| 客服信息 | 客服电话、邮箱、服务时间、反馈处理负责人 | 正式企业渠道，不使用乙方个人联系方式 | 中；同步隐私指引和页面 |
| 版权/底部信息 | 企业名称、版权年份、备案号展示位置 | 对外统一口径 | 中；备案号必须按规则展示并链接查询系统 |

## 4. 平台账号、权限与资产（P0）

| 项目 | 甲方需提供/确认 | 验收证据 | 变更代价 |
|---|---|---|---|
| 微信小程序账号 | 完成企业主体注册，账号由甲方控制 | AppID、主体信息和管理员页面截图 | 极高 |
| 微信认证 | 确认是否已认证、到期日、认证联系人和审核费用由谁支付 | 认证状态截图/订单 | 高；过期可影响云服务、能力申请或改名 |
| 成员权限 | 增加开发者、体验成员、运营者；坚持最小权限 | 成员列表截图 | 低；人员离项同日回收 |
| AppID | 只在受控项目配置中使用 | 项目可编译、体验版可打开 | **极高**；AppID 本身不能改成另一个，更换等同换小程序账号 |
| AppSecret/上传密钥 | 甲方管理员保管，通过密码管理器分发 | 开发/测试环境可用，仓库无明文密钥 | 中高；重置后旧密钥立即失效，所有环境需同步更换 |
| 微信云开发/腾讯云 | 云账号归属甲方，确认实名主体、费用预警、管理员和备份 | dev/test/prod 环境和费用预警截图 | 高；跨账号迁移可涉及数据、函数和域名 |
| 代码仓库 | 甲方组织下的私有仓库，乙方仅获必要权限 | 甲方可独立拉取、构建、回退 | 高；若仅在个人账号，交接风险高 |
| 域名和证书 | 域名所有人、ICP 备案主体、DNS、HTTPS 证书均由甲方管理 | 合法域名列表，证书有效期，到期提醒 | 高 |
| 地图/地址服务 | 确认地图供应商、Key 归属、调用配额和地址解析需求 | 甲方账号下的 Key 及配额预警 | 中高 |
| 设备云/硬件平台 | 正式账号、测试样机、设备 ID、日志权限和供应商联系人 | 真实样机能返回位置、在线状态和指令结果 | 极高 |
| SaaS 平台 | 测试账号、接口说明、联调环境、负责人和故障升级方式 | 账号、孩子、成果与成长数据可校验 | 高 |

## 5. 工信部备案与行业资质（P0）

甲方应设置一名备案负责人，并准备以下材料：

- 主办单位全称、性质、证件类型/号码、注册地址和通信地址。
- 主体负责人和小程序服务负责人的姓名、证件、手机、应急联系方式、电子邮箱及人脸/短信核验配合。
- 小程序名称、图标、AppID、运行平台、服务内容、类目、语种和 SDK/第三方服务清单。
- 互联网信息服务承诺书及平台临时要求的其他材料。
- 若被认定为教育、校外培训等需前置审批的服务，甲方需提供相关主管部门文件；不能用修改文案的方式规避实际业务性质。

工信部规定：小程序等 APP 应先完成备案再开展服务；材料齐全准确时，省级通信管理局应在 20 个工作日内予以备案。小程序名称、图标、主体、类目等备案信息变更后，应及时履行变更手续，不是只改微信后台即可。

**变更代价：**

- 应用名称、图标、负责人或类目变更：高，需同步平台与备案信息。
- 企业仅更名且统一社会信用代码不变：高，通常需提交工商变更证明并变更备案。
- 无关联的 A 主体更换为 B 主体：极高，可能需注销原备案或小程序迁移、重新备案，期间可能影响服务。

## 6. 隐私、儿童信息与内容资料（提审前 P0）

| 项目 | 甲方需提供/确认 | 变更代价 |
|---|---|---|
| 用户协议 | 运营主体、服务范围、用户义务、账号处理、设备风险和争议解决 | 中；实质条款变更需告知用户 |
| 隐私政策 | 信息类型、目的、方式、保留期、共享对象、用户权利、联系方式 | 高；必须与代码、SDK 和实际数据一致 |
| 儿童个人信息保护规则 | 监护人同意、查阅/更正/删除、撤回、申诉和专门负责人 | **高**；本项目涉及孩子、位置和成长数据，不可用通用模板简单替代 |
| 微信小程序用户隐私保护指引 | 在微信后台逐项声明手机号、微信昵称/头像、位置、设备信息等真实处理项 | 高；未声明的隐私接口可无法调用或审核驳回 |
| 个人信息清单 | 区分家长信息、儿童信息、设备位置、音频/通话元数据、操作日志 | 高 |
| 第三方 SDK/服务清单 | 名称、供应商、目的、数据类型、隐私政策链接、是否出境 | 高；增换 SDK 需重做合规和测试 |
| 位置处理规则 | 只显示 mini 设备当前有效位置；确认是否存储、保留多久、谁可查看；不展示历史轨迹 | **高** |
| 语音通话规则 | 确认是否录音、是否存储、通话记录范围、授权和故障告知 | **极高**；变更会联动硬件、平台能力和隐私 |
| 账号注销与数据删除 | 冷静期、主管理员责任、无法删除的法定保留数据和处理时限 | 高 |
| 正式文案/图片/指南 | 玩机指南、FAQ、设备安全提示、客服话术和上线内容 | 低至中；审核前必须替换演示文案 |

微信对涉及个人信息的小程序要求先配置隐私保护指引并完成用户同意流程，否则相关隐私接口可无法调用。

## 7. 开发、联调和审核配合资料

### 7.1 开发前甲方提供

- 最新 PRD、Figma 原型、正式功能范围和不开发清单。
- 家庭、孩子、监护人、设备、位置、成长数据的业务规则和权限矩阵。
- 多孩子、多设备、主管理员转移、解绑、删除和注销规则。
- SaaS 接口负责人、测试账号、接口说明和故障处理 SLA。
- 硬件供应商联系人、样机、设备云账号、协议与日志权限。
- 语音通话平台能力/设备型号资质申请的责任方与完成日期。

### 7.2 提审前甲方提供

- 长期有效的审核账号、测试家庭、测试孩子和可用测试设备。
- 审核人员操作说明，涵盖登录、绑定、位置、设备工具、成长与注销。
- 隐私政策、儿童信息保护规则、用户协议、SDK 清单和权限用途。
- 小程序名称、头像、介绍、类目、标签、客服信息和备案号的最终核准截图。
- 同意提审的版本号、发布日期、灰度范围、回滚负责人和上线窗口。

## 8. 关键平台信息的变更规则

| 信息 | 当前建议口径 | 对 AILab 的决策建议 |
|---|---|---|
| 小程序主体 | 不能当作普通文字字段任意替换；无关联主体变更可涉及小程序迁移、账号/数据迁移和重新备案 | 必须一开始使用最终运营公司，禁止登记在开发者个人名下 |
| AppID | 账号的固定标识，不可通过“修改设置”变成另一 AppID | 冻结后写入环境清单，不要在群聊里与 AppSecret 一起传播 |
| 小程序名称 | **企业主体不应简单套用“每年只能改两次”。**公开运营资料的常见口径为：发布前可直接改名 2 次；非个人主体发布后通常需进入微信认证/改名审核流程。个人主体才常见“每自然年 2 次”。 | 首发前一次确定品牌名，另准备备选名和权利证明；不把上线后改名当作无成本操作 |
| 头像 | 微信接口存在“本月头像修改次数已用完”错误码；公开实操资料常见为每月 5 次，但不同注册/代管路径可显示不同额度 | 开工时由管理员截图当前后台“剩余次数”；不依赖口头记忆 |
| 功能介绍 | 微信接口存在“本月功能介绍修改次数已用完”错误码；常见公开口径为每月 5 次 | 提审前定稿，介绍必须与当期真实功能一致 |
| 服务类目 | 平台规则和资质会更新；常见公开运营口径为最多 5 个类目、每月 3 次修改，但必须以本账号后台即时显示为准 | 不为了审核方便选择与功能不符的类目；硬件与语音能力需提前做类目/资质预审 |
| 备案信息 | 名称、图标、主体、负责人、类目等发生变更时应履行变更手续 | 将“微信后台修改＋备案变更＋必要时代码提审”当作一个完整变更包 |
| 隐私保护指引 | 收集信息、用途、SDK 或权限变更后需同步更新；未声明的隐私接口可不可用 | 隐私变更必须与代码版本同步，不允许只改文档或只改代码 |
| 管理员 | 可通过平台流程更换，但通常需原管理员或主体资料完成验证 | 人员离职前完成交接，不要等账号失控后再申诉 |

> 说明：微信后台会根据账号类型、是否发布、是否认证及平台最新规则显示当前剩余额度。涉及修改次数的结论，应在实际账号开通后由管理员提供后台截图作为项目证据；不同年份的第三方教程存在“每月 5 次”与“每年 5 次”等冲突，不应盲目采信。

## 9. 甲方签字确认页

### 9.1 开发启动前

- [ ] 企业主体、法定代表人、管理员与注册邮箱已确认。

- [ ] 定位、语音通话及设备工具的真实能力和责任方已确认。
- [ ] 小程序、云平台、代码仓库、域名、SaaS 和设备云均归甲方主体管理。

### 9.2 联调前

- [ ] SaaS 测试环境、正式接口和负责人已提供。

- [ ] 数据主体、数据保留期和删除责任人已确认。

- [ ] 审核账号、测试家庭、测试孩子和测试设备可长期使用。
- [ ] 小程序名称、头像、介绍、类目、客服与页内文案相互一致。
