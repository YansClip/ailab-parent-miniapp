## 2. 证据分级与复验入口

### 2.1 分级

- **S：静态/注册。** 文件四件套、JavaScript 语法、已识别的事件方法、静态路由、组件/资源路径、组件选择器与选择器属性回退检查；注册测试加载全部 Page/Component/App。S 不运行微信布局引擎，不是完整 WXML 编译或视觉测试。
- **C：控制器。** 在 Node 中构造 Page，模拟 wx 平台对象，调用生命周期/事件并核对页面数据、API 结果与路由。多数异步任务使用可控业务时钟及排队计时器；不把计时器注册直接当作设备完成。
- **M：服务/状态。** 本地 API 门面、任务、主体权限、缓存迁移、会话、事件、成长映射、报告快照测试。
- **G：实际 GUI。** 本轮微信开发者工具可见界面的检查。只有第 5 节列出的范围属于 G；不存在“46 页全部手动走完”的本轮证据。
- **P：物理真机/真实外部链路。** 本轮未完成，不从 S/C/M/G 推导为通过。
