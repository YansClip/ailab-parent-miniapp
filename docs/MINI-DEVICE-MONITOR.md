# mini 设备联调窗口

2026-10-02 新增：小程序可与本机联调台配对，查看所选 TCP 连接的点位，并同步语音 / 视频**信令模拟**。使用步骤和最新验证结果见 [小程序 × mini 本机联调](MINI-LOCAL-LAB.md)。

## 怎么打开

1. 本机已安装后台常驻服务，登录当前 Mac 用户后自动启动。需要手动恢复时，双击 `tools/mini-location-tcp/启动接收程序.command`；安装常驻服务后不必保持终端打开。
2. 浏览器打开 **http://127.0.0.1:18866**。窗口每秒更新，不必反复询问是否收到数据。
3. 日常使用窗口里的“开启接收 / 停止接收”。停止会断开设备 TCP 连接并清除临时原文，但保留窗口、摘要和音视频监控；重新开启可以继续测试。
4. 要停用整个工具，双击 `停止接收程序.command`。这会停用后台常驻，避免自动拉起，并关闭本窗口启动的公网入口；下次双击启动脚本会重新启用。关闭网页或终端本身不会停止后台服务。

常驻服务命令：`node tools/mini-location-tcp/service.js start` / `stop` / `status`。没有安装常驻服务的其他电脑仍可用 `npm run device:tcp` 前台运行，需保留该终端。不要同时启动常驻和前台版本占用相同端口。只启动本机接收，不自动开启公网。

### 常驻与自动恢复的边界

- 当前 Mac 通过用户 LaunchAgent `com.ailab.mini-device-monitor` 管理，配置位于 `~/Library/LaunchAgents/com.ailab.mini-device-monitor.plist`。进程退出后自动重启；频繁退出时系统会限制重试频率。
- 浏览器在服务重启后自动重新取得本机页面令牌并恢复轮询，不重放开启公网、通话等操作。
- 重启会断开已有 TCP 连接、清空内存中的临时记录及模拟会话；设备端仍需具备断线重连能力。这不是零中断保证。
- 电脑关机、睡眠、退出当前 Mac 用户或断网时，不能保证服务/远程连接可用。本次未修改电源设置。
- 公网穿透仍需手动开启、到期关闭，服务重启不会自动重开公网或续期。异常退出遗留的会话锁应确认进程已结束后处理，不绕过占用保护。
- 后台标准输出丢弃，不持续生成报文或位置日志。浏览器中可查看短期诊断信息。

右上角“切换深色 / 切换浅色”只改变显示主题，不影响接收、公网或音视频会话。选择保存在当前浏览器，刷新后保留；浏览器禁用本地存储时仍可切换，但不保证刷新后记忆。仅存储主题偏好，不存储报文、位置或凭证。

远程测试不需要另开程序：在同一窗口先“开启接收”，勾选只发送合成数据，选择 15 / 30 / 55 分钟，再点击“开启公网测试”。等实际地址出现后，点击定位页“复制给工程师”。结束时点击“关闭公网测试”；本机接收和音视频窗口不受影响。只停止接收不会关闭尚未到期的公网入口。

公网入口由 Pinggy 第三方提供，只转发本机 18765 TCP 端口；到期自动关闭、不自动重连，重开可能更换地址。未经设备认证及端到端加密验证，只允许合成坐标。**绝不转发 18866 监控端口。**

按钮不安装软件、不购买服务、不使用个人 SSH 密钥。网络异常、申请超时、端口占用或已有会话锁会明确报错，不显示假成功。使用旧命令行 `device:tcp:tunnel` 启动的会话，先用原终端或停止远程测试脚本结束，再使用窗口方式；不强行接管旧会话。

## 定位页看什么

| 显示 | 实际含义 |
|---|---|
| TCP 连接 | 有连接，不等于设备已认证 |
| 收到字节 | 网络送来了片段，不保证是一整条消息 |
| 组成报文 | 按换行符组成完整消息 |
| 完整坐标 | 经度在前、纬度在后，格式及范围通过；还不是正式定位有效性判断 |
| 注册信息 | 设备上线包，不是经纬度 |
| 等待换行 | 尚未收到完整 LF；超时后会断开 |

- 默认不显示原文；点击“临时查看原文”后，仅捕获随后 60 秒的新报文。
- 点击记录可以检查原文与 HEX。`0D 0A` 是真正的 `\r\n`；字符 `\\r\\n` 不是换行。
- 原文最多 8 条、每条 512 字节，自动过期，不写磁盘；切走网页后主动关闭临时查看。
- 摘要最多 100 条、保留 5 分钟。“清空摘要”不重置累计计数。
- 本机自测使用合成坐标，计入总数且有明确自测提示，不能当作硬件上报证据。
- 接收器默认坐标系仍标记 UNKNOWN，不猜测转换。新增配对入口允许明确选择所选连接上传值的 WGS84 / GCJ-02；未知时不显示地图，只向配对后的开发者工具输出未认证联调点位。
- 公网未认证 / 未确认端到端加密期间，只传合成坐标，不传真实儿童位置。

## 音视频页看什么

支持语音 / 视频、准备呼叫、呼叫、等待接听、媒体连接、上报接通、结束，以及拒接、离线、无人接听模拟。**不会发起真实呼叫，不打开摄像头或麦克风，不播放或录制。**

会话卡分别显示孩子接听、媒体就绪和视频就绪的上报标记。客户端上报不能独自确认接听。标记齐全也不代替正式鉴权和真实样机验证。已结束会话收到迟到接通事件不会恢复；同来源重复 / 乱序事件会标记忽略。

网络质量可接收往返延迟、抖动、丢包率、音视频码率、视频帧率；缺失显示“暂无数据”。指标显示来源和接收时间，是最近一次采样，不保证持续有效。最多 24 个会话 / 120 条事件，保留 10 分钟，仅在内存。

## 后续开发者如何上报音视频联调数据

这不是厂家协议，也不是正式通话后台。它是**运行在同一台电脑的诊断接口**。未来真实 SDK / 云端回调需要经过认证的适配程序转成下列结构；云服务器不能直接访问这台电脑的 `127.0.0.1`。

本机适配代码可以直接调用：

```js
const { sendEvent } = require('./tools/mini-location-tcp/media-send')
await sendEvent({
  callId: 'lab-call-001', // 使用脱敏联调编号，不传手机号或真实设备序列号
  mediaType: 'video',    // voice | video
  source: 'gateway',    // client | device | gateway | sdk；当前只是来源声明，不是认证
  seq: 1,               // 每个 callId + source 内递增，从 0 或 1 开始
  state: 'connected',
  childAccepted: true,
  mediaReady: true,
  videoReady: true,
  metrics: { rttMs: 85, jitterMs: 12, packetLossPct: 0.6, audioKbps: 32, videoKbps: 850, fps: 24 }
})
```

以上仅为字段示例，不能在真实未接通时发送 connected。命令行也可使用 `node tools/mini-location-tcp/media-send.js --file 脱敏事件.json`。此脚本仅访问 loopback，启动监控后自动取得短期页面令牌，不输出令牌、不写凭证文件。

必填：`callId / mediaType / source / seq / state`。

可选：`childAccepted / mediaReady / videoReady` 布尔值；`errorCode` 大写字母、数字和下划线；`metrics` 中的上述数值字段。

状态枚举：`preparing / calling / ringing / connecting / connected / ending / ended`。同一通话的媒体类型不能改变。已结束后重新拨打必须使用新 callId。

接收结果 `{ accepted: true }` 只表示监控收录，**不是业务 ACK / 通话成功**；`accepted: false` 含忽略原因。非法字段 / 类型返回 HTTP 400。错误说明不回显输入内容。

禁止传入音视频内容、Token、密码、SDP、ICE、TURN 凭证、手机号、儿童资料或真实设备号；非白名单字段直接拒绝。本机程序具有本机信任范围，不提供远程设备鉴权。模拟与本机上报使用不同命名空间，互不覆盖。
